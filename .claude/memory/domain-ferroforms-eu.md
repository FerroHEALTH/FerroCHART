The public domain is **ferroforms.eu**, bought by the owner in October 2026,
and the product name is **FerroFORMS** (`ferroforms` in identifiers). GitHub
Pages serves the custom domain, and the repository is
`FerroHEALTH/FerroFORMS`.

**History:** the product was called FerroCHART from 2026-09-06 to v0.1.1, on
ferrochart.eu (Vimexx, the family's zxcs nameservers), because ferroform.eu
was already registered. The owner then bought ferroforms.eu and renamed the
product. Released tags and released changelog sections keep the old name.

**How to apply:**

- The domain is a Pages setting, never a committed `CNAME` file.
- Write FerroFORMS in prose and `ferroforms` in identifiers. FerroCHART
  appears only where history is recorded: released changelog sections, tags,
  and the artifacts and images those releases published.
- Never write FerroFORM (singular): ferroform.eu belongs to someone else.
